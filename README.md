# Аким на 5 часов

Интерактивный AI-симулятор распределения городского бюджета. Команда начинает с одинаковых исходных данных и бюджета, выбирает ровно по одной инициативе в пяти направлениях, затем получает **Astana Quality of Life Score** и разбор сильных сторон, рисков и компромиссов.

Сценарий демонстрационный: районы, население, показатели, стоимость и эффекты инициатив синтетические и не являются официальной статистикой или сметой.

## Возможности

- Единый бюджет **100 условных единиц** и одинаковый датасет для каждого запуска.
- Три условных района: Есиль, Алматы и Сарыарка; в каждом заданы показатели по пяти направлениям и численность населения.
- Пять решений: транспорт, озеленение, социальная инфраструктура, безопасность и городской сервис. На каждое направление доступны три инициативы с ценой, районом и эффектами.
- Перерасчёт доступного бюджета и показателей по мере выбора; сервер отклоняет превышение бюджета и повторный выбор направления.
- Итоговый взвешенный **Astana Quality of Life Score**, сравнение с базовым уровнем, районные показатели и AI-анализ решений.
- Если AI API не настроен или недоступен, приложение показывает автоматический разбор на основе той же модели и результатов расчёта.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес Vite, который появится в терминале (обычно `http://localhost:5173`). Для production-сборки используйте `npm run build`, затем `npm start`.

## Подключение AI

Приложение работает и без ключа. Чтобы получать разбор от языковой модели, скопируйте `.env.example` в `.env` и задайте `OPENAI_API_KEY`. Сервер обращается к OpenAI-совместимому `POST /chat/completions`; можно указать совместимого провайдера через `OPENAI_BASE_URL` и модель через `OPENAI_MODEL`. Ключ остаётся на сервере и не попадает в браузер. При недоступности провайдера сценарий и Score продолжают работать, показывается локальный аналитический разбор.

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
OPENAI_BASE_URL=https://api.openai.com/v1
PORT=3001
```

## Модель расчёта

Каждый район имеет синтетические значения 0–100 по пяти направлениям. Выбранная инициатива прибавляет или вычитает заданные пункты в целевом районе. Значения ограничиваются диапазоном 0–100. Для каждого направления рассчитывается среднее по районам, взвешенное численностью населения. Итоговый балл — взвешенная сумма пяти городских показателей:

| Направление | Вес |
| --- | ---: |
| Транспорт | 25% |
| Озеленение | 20% |
| Социальная инфраструктура | 20% |
| Безопасность | 20% |
| Городской сервис | 15% |

Итоговый Score — аналитическая модель симулятора, а не официальный индекс качества жизни Астаны. AI получает выбранные меры, стоимость и уже рассчитанные метрики. Он объясняет результат и предлагает рекомендации, но не меняет бюджет, показатели или Score.

## Основной сценарий

1. Откройте направление и сравните три инициативы, стоимость, район назначения и сопутствующий эффект.
2. Выберите по одной мере для каждого из пяти направлений. Бюджет и районные показатели обновляются автоматически; набор, превышающий общий лимит, нельзя выбрать.
3. После пяти решений нажмите **«Получить AI-разбор»**.
4. Сравните итоговый Score с базовым, посмотрите динамику районов и прочитайте сильные стороны, риски и рекомендации. Набор инициатив можно изменить и пересчитать.

## Устройство проекта

- `src/ui/App.jsx` — интерфейс выбора мер, бюджет, Score и аналитика.
- `src/ui/styles.css` — адаптивная визуальная система.
- `server/index.js` — API сценария, серверная проверка бюджета, расчёт показателей и AI-разбор.
- `data/scenario.json` — единый сценарий, районы, веса показателей, меры, цены и эффекты.

API: `GET /api/scenario`, `POST /api/score` с `{ "selectedIds": [...] }`, `POST /api/analyze` с полным набором из пяти ID.
